How to add as app

For more play space, launch from a Home Screen icon instead of a browser tab.

  1. On iPhone, open this game in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Enable Open as Web App if offered, then tap Add.
  4. Launch the new game icon and turn your phone sideways.

Chrome on iPhone also offers Share → Add to Home Screen. If unavailable, use Safari. On Android Chrome, use the menu → Add to Home screen / Install app when offered.

Browser menus vary. Expanded view cannot force browser bars to hide. Internet is required; Home Screen scores and settings may be separate from your browser.
