# Seth Happens!

[Play the game](https://natsteff.github.io/seth-happens/)

A fictional rooftop beer run to floor 26. Move with A/D or arrows, jump with Space, F for photos/finish, V for fullscreen, S for sound, C for jump clues, B for missed photos, hold R to restart.

Scores stay in your browser. Clear-password protection deters casual clearing; it is not server authentication.

Development: pnpm install, pnpm dev. Build: pnpm build. Tests: pnpm test.
